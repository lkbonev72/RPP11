## Опорни точки

### Функции

| Така не | Така да |
|---|---|
| `def f(x, y): ...` | `def average(grades: list) -> float: ...` |
| функцията печата резултата | функцията връща резултата; печата този, който я вика |
| функция от 80 реда | функция до ~20 реда с една отговорност |
| резултатът се пази в глобална променлива | резултатът се връща с `return` |
| без docstring | първи ред: `"""Едно изречение какво прави."""` |

### Списък или речник?

| Въпросът | Списък | Речник |
|---|---|---|
| Как търся елемент? | по позиция (0, 1, 2…) | по ключ (име, код, дата) |
| Важен ли е редът? | да | да, но не се използва за търсене |
| Типичен случай | оценките на един ученик | оценките на целия клас по име |
| Колко бързо намира? | бавно при много елементи | бързо, независимо от броя |

### Трите антипатърна при изключенията

```python
# АНТИПАТЪРН 1: голо except — хваща дори Ctrl+C и SystemExit
try:
    risky()
except:
    pass

# АНТИПАТЪРН 2: мълчаливо преглъщане — грешката изчезва без следа
try:
    value = int(user_input)
except ValueError:
    value = 0        # откъде да знам, че потребителят е сбъркал?

# АНТИПАТЪРН 3: try върху половин програма — не се знае кой ред е гръмнал
try:
    data = read_file(path)
    result = process(data)
    save(result)
except Exception:
    print('Нещо се обърка')
```

> **Правилото за цялата година:** прехващай най-конкретното изключение, което можеш да назовеш, върху най-малкия блок код, който може да го предизвика, и направи нещо смислено с него. Ако не знаеш какво смислено да направиш, не го прехващай.

## Критерии за оценяване (15 точки)

| Показател | Точки | Как се проверява |
|---|---|---|
| Функции с говорещо име, docstring и return | 2 | нито една функция не печата и не смята едновременно |
| Правилно използване на речник за моделиране на данните | 2 | няма паралелни списъци, които трябва да се държат синхронни |
| Прехванато е конкретно изключение, не Exception/голо except | 3 | в кода няма `except:` и няма `except Exception` без повдигане нагоре |
| Дефиниран и използван собствен клас изключение | 2 | изключението носи полезна информация, не само текст |
| Програмата не спира при една проблемна позиция | 3 | проверка с подготвен списък от 6 сценария |
| Писмен отговор на въпроса от задача 2.1, т. 5 | 3 | аргументация, не преразказ |
