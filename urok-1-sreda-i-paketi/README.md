# Урок 1. Организация на Python проект. Виртуална среда, пакети и requirements файл

**Теми в НЕИСПУО: 1–2**

След урока можете да:

- създадете и активирате виртуална среда и да обясните какво се променя при активирането ѝ;
- инсталирате пакет и да запишете зависимостите в `requirements.txt` с точни версии;
- възстановите чужд проект на своя компютър само по неговия `requirements.txt`;
- обясните защо папката `.venv` не се качва в хранилището;
- назовете поне един конкретен риск при инсталиране на пакет от PyPI.

**Понятия:** интерпретатор · виртуална среда (venv) · пакет · зависимост · транзитивна зависимост · PyPI · pip · requirements.txt · закачане на версия (pinning) · .gitignore · typosquatting

## Ключови команди

| Действие | Windows (cmd) | Windows (PowerShell) | macOS и Linux |
|---|---|---|---|
| Създаване на среда | `python -m venv .venv` | `python -m venv .venv` | `python3 -m venv .venv` |
| Активиране | `.venv\Scripts\activate` | `.venv\Scripts\Activate.ps1` | `source .venv/bin/activate` |
| Кой Python работи | `where python` | `where.exe python` | `which python3` |
| Инсталиране на пакет | `python -m pip install rich` | `python -m pip install rich` | `python -m pip install rich` |
| Списък на инсталираното | `python -m pip freeze` | `python -m pip freeze` | `python -m pip freeze` |
| Записване на зависимостите | `python -m pip freeze > requirements.txt` | `python -m pip freeze \| Set-Content -Encoding utf8 requirements.txt` | `python -m pip freeze > requirements.txt` |
| Възстановяване на чужд проект | `python -m pip install -r requirements.txt` | `python -m pip install -r requirements.txt` | `python -m pip install -r requirements.txt` |
| Излизане от средата | `deactivate` | `deactivate` | `deactivate` |

**Защо `python -m pip`, а не само `pip`?** Така pip принадлежи на точно този Python, който изпълнявате. Командата `pip` може да е от друг Python в системата, а точно за това е целият урок.

Ако PowerShell откаже да активира средата: `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass`.

### Структура на проекта, която използваме до края на годината

```
citat_na_denya/
    .venv/              <- виртуалната среда (НЕ влиза в Git)
    .gitignore
    requirements.txt    <- от какво зависи проектът
    README.md           <- какво прави и как се стартира
    citat.py            <- кодът
    data/
        citati.txt
```

### Проверка на пакет преди инсталиране

Преди `pip install` на непознат пакет отворете страницата му в [pypi.org](https://pypi.org) и проверете:

1. **точното име**, буква по буква: `jellyfish` и `jeIlyfish` (с главно I) са различни пакети;
2. **кога е последната версия** и колко версии има;
3. **има ли връзка към хранилище** с изходния код;
4. **кой е авторът** и има ли други пакети.

## Задача 1.2. Цитат на деня — пълният проектен цикъл (задължителна, ~20 мин)

Папка: [`citat_na_denya/`](citat_na_denya/)

В папката вече има `data/citati.txt` с цитати във формат `текст | автор`. Останалото създавате вие. Всяка стъпка се проверява преди следващата.

1. В папката `citat_na_denya` създайте виртуална среда `.venv`.
2. Активирайте средата и се уверете, че сте в нея: `python ../demo/env_check.py`.
3. Инсталирайте `rich`. Отбележете колко пакета всъщност се инсталираха.
4. Запишете `requirements.txt` и го отворете. Трябва да видите версии с `==`.
5. Напишете `citat.py` така, че цитатите да се четат от `data/citati.txt`, а не да са в кода. Можете да започнете от `../demo/citat.py`.
6. Добавете `.gitignore` и `README.md` с две изречения: какво прави програмата и как се стартира.
7. Направете комит и `git push`.
8. **Размяна по двойки.** Клонирайте fork-а на съученика си в **отделна папка, извън вашето хранилище**:
   ```
   cd ..
   git clone https://github.com/<съученик>/RPP11.git sauchenik
   cd sauchenik/urok-1-sreda-i-paketi/citat_na_denya
   ```
   Създайте нова среда, инсталирайте само по неговия `requirements.txt` и стартирайте програмата му.

*Последната стъпка е истинската проверка на урока. Ако проектът на съученика не тръгва само по requirements.txt, значи нещо липсва в него. Открийте какво.*

## Критерии за оценяване (10 точки)

| Показател | Точки | Как се проверява |
